# Changelog

## v0.1.0 — first public release

- Quad 34 preamplifier: all serial ranges (up to 6000, 6001–8000, from 8001 incl. late RCA units).
- Full recap (DADA kit route and RATA 1993 route), with polarity traps and voltage-rating notes.
- Disc stage: all four Quad modules (MM 3mV; MC 100µV, 200µV, 400µV), MM loading mod, Keith Snook MC low-noise mod, disc-to-line-input conversion.
- Output level changes, balance control repair, op-amp decoupling, early-unit CD/tape input mods.
- Quad test procedure figures and fault-finding diagnoses.
- Conflicts between sources flagged (R34/R38, D1/D2, fuse rating, C74 voltage).
- All component data provisional pending board verification.
