# Owner pages — plain-English text

Each file here is the wording for one model's web page (`docs/models/<model>.html`), written for owners rather than for the AI. `scripts/build_site.py` reads it and adds the documents and parts list from the rest of the repository.

Write for an adult who is new to electronics. Aim for something a bright 14-year-old could follow on first reading:
- one idea per sentence, everyday words, and say what a part does before naming it
- no part numbers, source IDs or abbreviations
- tell them what to do next, not everything we know
- every fact must also be in the model's reference files, which cite the source

Sections, in this order: `## What it is`, `## Write these down`, `## What a recap does`, `## Optional extras`, `## Good to know`. Bullet lists use `- `. `**bold**` is allowed.
