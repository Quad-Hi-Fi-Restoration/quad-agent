# Source documents

This folder holds the source material used to build and verify the restoration guides: service manuals, circuit diagrams, DADA Electronics kit instructions, and community upgrade notes. There is one folder per model (`quad-34/`, `quad-33/`, `quad-303/`, `quad-306/`, `quad-405/`, `quad-44/`, `quad-606/`).

Each supported model's source list and credits are in its `quad-upgrade/reference/<model>/source-register.md` (supported models are listed in [`quad-upgrade/reference/index.md`](../quad-upgrade/reference/index.md)); the inventory for the other models is in [`research-register.md`](research-register.md).

## Adding documents

Put the file in the right model folder and record its title, author or publisher, revision/date, where it came from, and what it covers in the source register, so the guides can cite it and its authors get credit.

Some documents are scanned images. Inspect page images when text extraction is empty or unclear. Record uncertainty and source conflicts; never fill gaps by guessing.

`inbox/` is ignored by Git if you want somewhere to keep files you don't intend to commit.
