# source-docs

Drop your service manuals, factory update sheets and community upgrade sheets here, one folder per model (e.g. `quad-34/`).

This folder is git-ignored: files here stay on your PC. Only publish a document if its owner has given permission.

Suggested file naming so citations stay readable:

```
quad-34/Quad-34-service-manual-issue-X.pdf
quad-34/<author>-phono-upgrade-sheet-<year>.pdf
```
