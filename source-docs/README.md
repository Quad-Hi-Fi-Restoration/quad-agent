# Source documents

The skill's data is distilled from the documents below. Copies are kept in `quad-34/` for reference. They remain the property of their authors and are **not** covered by this repository's licences. If you own one of these documents and want it removed, open an issue and it will be taken down promptly.

Original download locations are listed so you can always get the document from its source.
