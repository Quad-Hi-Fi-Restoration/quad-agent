# Quad 34 — community verification log

Only a person competent to work safely inside mains-powered equipment should inspect a physical board. Beginners should have a qualified technician perform the check. Use one entry for each physical unit checked. A check against one board verifies only that observation; it does not establish that every serial range or board revision is the same.

Give every completed observation a unique ID declared in the source index (the existing maintainer-observation ID is `O1`). Use that ID as the entry heading. BOM rows may be marked `verified` only when their `source` includes an ID whose full observation is recorded here.
