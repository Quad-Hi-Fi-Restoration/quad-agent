# [MODEL] physical verification log

Use one dated entry per inspection. Only a person competent to work safely inside mains-powered equipment should inspect the board; beginners should have a qualified technician perform the check. Record only what was observed on the named unit; do not generalize it to other serials or board revisions. Declare each observation ID in `source-register.md` before citing it in a BOM row.
